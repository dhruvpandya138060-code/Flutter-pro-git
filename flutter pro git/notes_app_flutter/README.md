# Notes App — Flutter Udemy course project

A Flutter notes CRUD app based on the Udemy course sections **GetX State Management** and **Local Storage / SQLite**. This project is a reconstruction from course screenshots, not the instructor's original source code.

## Features
- List notes, create notes, edit existing notes, delete notes with confirmation
- Required-field validation and persistent local data
- GetX controller with reactive `RxList` and `Obx`
- SQLite (`sqflite`) database on Android and iOS
- `shared_preferences` JSON persistence on web (Chrome) because `sqflite` doesn't run directly in browsers

## Run
Install Flutter, then open this project in VS Code and run:

```powershell
flutter create .
flutter pub get
flutter run -d chrome
```

For an Android phone or emulator use `flutter run -d <device-id>` (run `flutter devices` to see IDs). This uses SQLite. The Chrome version persists notes in browser local storage instead.

## Code tour / Viva
- `lib/main.dart`: `GetMaterialApp` and dependency registration via `Get.put`
- `lib/models/note_model.dart`: note model and map serialization
- `lib/controllers/note_controller.dart`: GetX reactive state and CRUD actions
- `lib/database/database_helper.dart`: SQLite table and database queries; browser fallback
- `lib/screens/note_list_screen.dart`: notes list, delete dialog and add button
- `lib/screens/note_detail_screen.dart`: create/edit form and validation

**GetX:** `Obx` rebuilds widgets when the observed data changes. **SQLite:** embedded relational database where notes are saved in a table. **CRUD:** Create, Read, Update, Delete.
