# First App — Hello World (Flutter)

A simple Flutter application demonstrating `MaterialApp`, `Scaffold`, `AppBar`, `Container`, `Center`, and `Text`.

## Setup

The ZIP contains the application source and Flutter configuration, but no generated Android/iOS/web platform folders. Install Flutter, then open a terminal in this folder and run:

```sh
flutter create .
flutter pub get
flutter run -d chrome
```

For an Android emulator/device, use `flutter run` after configuring your device.

## Test

```sh
flutter test
```

## What it displays

A top app bar labelled **First App**, with centered white **Hello from first app** text on a red background.
